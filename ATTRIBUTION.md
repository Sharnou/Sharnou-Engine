# Architecture attribution

Sharnou Engine is an independent C++23 implementation inspired by the lean, modular philosophy of engineerOfLies/gfc (Game Framework Common).

The referenced gfc repository is MIT-licensed. This project does not copy its source files into the engine core; it adopts the idea of a compact common framework layer and rebuilds the runtime in modern C++23 around an ECS, a bounded job system, Direct3D 11, and strict AVIF texture handling.
